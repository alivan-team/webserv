About This Project

Webserv - HTTP Server in C++17

This website is a test suite for the webserv project, part of the 42 CODAM curriculum.

The project implements a fully functional HTTP/1.1 server written in C++17, featuring:

  • Non-blocking I/O with poll()
  • Multiple server blocks on different ports
  • Virtual host support via Host header
  • Static file serving with MIME-type detection
  • Directory listing (autoindex)
  • File upload via multipart/form-data
  • CGI execution (.py, .sh, .php)
  • HTTP redirect (301, 302)
  • Custom error pages
  • Request body size limits

Configuration

The server uses a nginx-inspired configuration file format. Example:

server {
    listen 8080;
    server_name localhost;
    root ./site/www;
    index index.html;
    client_max_body_size 1000000;

    location / {
        allow_methods GET;
        autoindex off;
    }

    location /upload {
        allow_methods GET POST DELETE;
        upload_store ./site/www/uploads;
        autoindex on;
    }

    location /cgi-bin {
        root ./site/www/cgi-bin;
        allow_methods GET POST;
        cgi_extension .py;
        cgi_path /usr/bin/python3;
    }
}
