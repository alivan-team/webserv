Evaluator cheat sheet

What each route demonstrates.

/

Static website, index resolution, GET-only route.

/files/

Server-generated directory autoindex.

/upload

POST + multipart upload into a configured storage directory.

/uploads/

GET autoindex plus DELETE for individual files.

/cgi-bin/echo.py

Python CGI through fork/execve and non-blocking pipes; supports GET and POST.

/legacy

Configuration-driven HTTP 301 redirect.

/get-only

Method restriction demonstration: POST should return 405.

:8081

A second listening port serves different content from the same webserv process.
